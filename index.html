Kick API подтверждает состояние эфира. Просмотр доступен во вкладке «Смотреть» через официальный плеер Kick. OAuth-авторизация профиля отдельно не подтверждает просмотр. Время эфира отображается только при наличии данных о начале трансляции.

Подключения зрителей

Подключённые OAuth-профили подтверждают личность пользователя, а не просмотр. Для реального просмотра открой вкладку «Смотреть». Статус эфира — результат запроса к Kick API, а не статус просмотра твоего аккаунта.

Каналы по приоритету

Первый работающий канал по приоритету выбирается автоматически для мониторинга. Приостановленный канал не проверяется через Kick API. Эти настройки не запускают и не останавливают воспроизведение видео.

Диагностика Render и Node.js

RSS — память процесса Node.js. Память контейнера показывается отдельно, если Render предоставляет cgroup-метрики. Она включает другие процессы и системные накладные расходы.

Журнал событий

Последние 200 событий в памяти; после перезапуска сервера журнал начинается заново.

Смена пароля администратора

Новый пароль хранится в Supabase в виде стойкого хеша, а не открытого текста. После смены все сессии будут завершены.

SESSION_SECRET остаётся в Render. Для восстановления доступа можно изменить пароль только после входа; при проблемах с Supabase потребуется вмешательство администратора в базу.
