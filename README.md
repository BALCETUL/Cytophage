# Kick Monitor Light v1.4 — просмотр через официальный плеер Kick

**Новое:** вкладка «Смотреть» запускает официальный embedded player `https://player.kick.com/<channel>` только после нажатия «Начать просмотр» в браузере пользователя; кнопка «Остановить просмотр» удаляет iframe. Работает в открытом браузере, не в серверном процессе Render. Таймер открытия плеера не означает начисленного времени просмотра. Kick OAuth подтверждает ник и разрешения, а не участие в просмотре. Drops и учтённые часы проверяются на самом Kick. Не предназначено для накрутки зрителей или запуска скрытых аккаунтов.

**Если установлен OAuth v1.3:** все текущие переменные Render и Supabase остаются прежними. Для первой авторизации OAuth Redirect URI должен точно соответствовать адресу из README v1.3/конфигурации приложения.

# Архитектура существующего монитора

Лёгкий веб-сервис Node.js для определения статусов трансляций через официальный Kick API. **Не воспроизводит видео, не использует cookies аккаунтов и не подтверждает засчитанные просмотры.**

## Установка в существующий Render

Загрузите файлы ZIP в **корень** репозитория GitHub. В Render для существующего веб-сервиса укажите Build Command `npm install`, Start Command `npm start`, Node.js >=20. Переменные окружения:

- `ADMIN_PASSWORD` — первоначальный пароль администратора (не публикуйте).
- `SESSION_SECRET` — случайная строка минимум 32 символа.
- `KICK_CLIENT_ID` и `KICK_CLIENT_SECRET` — из приложения в Kick Developer.
- `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` — сохранение каналов и пароля. Не публикуйте ключ базы.

Пароль можно сменить в разделе **Безопасность**. Новый пароль сохраняется в отдельной записи `id=kick_monitor_auth` в существующей таблице `public.cytophage_world`. В поле `payload` хранится только 16-байтная соль и 64-байтный scrypt-хеш; открытого пароля там нет. При смене все сессии закрываются. Исходная переменная `ADMIN_PASSWORD` остается первоначальным резервным значением; **после изменения в панели применяется хеш из Supabase, а не пароль Render**. При полном удалении записи `kick_monitor_auth` после перезапуска снова применяется пароль из Render. Ограничьте доступ к Supabase service role.

Используется запись `kick_monitor` для каналов. **Запись Cytophage `main` не изменяется.**

## Управление

Панель открывается по Render URL `/` (например, `https://cytophage.onrender.com/`).

- **Обзор** — выбранный эфир, состояние каналов и сервера.
- **Каналы** — добавить, приостановить, возобновить, передвинуть или удалить канал.
- **Сервер** — RSS, JS heap, external, cgroup RAM при поддержке, ошибки и продолжительность работы.
- **Журнал** — последние 200 сообщений текущего запуска.
- **Безопасность** — сменить пароль, прочитать инструкцию по отключению GitHub Pages.

`/health` — быстрый ответ для cron-job.org. Он не гарантирует стабильную работу Render Free. Смена параметров безопасности требует перезапуска сервиса. Не запускайте несколько реплик на Free: настройки каналов и сессий рассчитаны на один процесс.

### Убрать публичную копию на GitHub Pages

GitHub → репозиторий → **Settings → Pages → Build and deployment → Source: Disable**. Панель на Render при этом не затрагивается. Удаление GitHub Pages не делает код в публичном репозитории приватным.

### Диагностика

В логах могут оставаться предупреждения `npm audit` из-за **старого package-lock.json** и `node_modules` предшествующего проекта. У текущего `package.json` нет внешних зависимостей. Если GitHub содержит старый `package-lock.json`, обновите/удалите его отдельно после проверки. **Не добавляйте cookies в GitHub.**

Показатель продолжительности эфира появляется только если Kick вернул достоверное время начала, иначе написано «Нет подтверждённых данных». Время просмотра **не отслеживается**.

## v1.3 — несколько аккаунтов Kick через официальный OAuth

Откройте вкладку **«Подключения»** → **«Подключить аккаунт Kick»**. В официальном окне Kick подтвердите разрешение `user:read`. Возврат происходит на **тот же URL**, который уже был указан при регистрации приложения: `https://cytophage.onrender.com/` (с конечным `/`). Если Render находится на другом домене, установите `RENDER_EXTERNAL_URL` равным точному внешнему адресу сервиса и зарегистрируйте его в Kick. Нельзя использовать GitHub Pages как redirect URL.

Можно подключить до 10 собственных или добровольно авторизованных профилей. Панель показывает ник, время подключения и позволяет удалить подключение. Данные аккаунтов хранятся в Supabase под ID `kick_monitor_accounts`, отдельно от каналов и Cytophage. Токены сохраняются зашифрованными (AES-256-GCM), ключ выводится из `SESSION_SECRET`. **Не меняйте SESSION_SECRET без предварительного отключения/повторного подключения профилей**: старые токены будет невозможно расшифровать. Не публикуйте токены, cookies, сервисный ключ Supabase.

**Ограничение:** OAuth подтверждает личность и право чтения профиля. Он не воспроизводит трансляции, не доказывает просмотры, не начисляет Drops или время просмотра. Текущая версия не имеет подтверждённого API для проверки зачтённого просмотра.

Если Kick вернул ошибку входа — проверьте, что Redirect URL в Kick совпадает с адресом сайта Render вплоть до конечного `/`. Для реальной проверки OAuth требуется одобрить доступ на стороне Kick: автономные локальные тесты не могут заменить этот шаг.
